# ComfyUI Image Compare Pro
Input images for precise comparing, featuring customisable background colour, transparent/alpha image supported. Slide the slider to view between input images. Contact:mmmmmmmmme_@outlook.com

## Features
- Precise comparing, no distortion guaranteed
- Customisable background colour
- Transparent/alpha image supported
- Draggable slider

## Install
Install through ComfyUI Manager by Searching **ComfyUI Image Compare Pro**

## How to use
1. Images as input
2. Click run workflow to get output mask
3. Slide the slider for comparing
4. Customise desire background colour for better view
